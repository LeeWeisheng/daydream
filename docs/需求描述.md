# 需求描述

## 项目概述

Daydream 是一款面向 A 股市场的 AI 量化决策辅助桌面应用。系统以「自动规划 → 自动生成策略 → 自动回测 → 自动运行 → 自动盯盘 → 自动复盘 → 自动纠正」为主链路，AI 自主完成策略构思、验证、决策与迭代的完整闭环，产出交易建议；交易由人工执行，人工同时负责监督与兜底。

## 行业共识

社区主流量化平台（QMT、PTrade、掘金、聚宽、米筐等）已形成「数据 → 研究 → 回测 → 模拟 → 实盘 → 分析」的一体化能力共识。本项目借鉴其中的数据、研究、回测与分析能力，不涉及模拟盘与实盘交易（交易由人工完成），并以 AI 全自动决策闭环替代人工研究驱动，形成核心差异。

## 核心目标

- 决策闭环自动化：从规划到纠正的决策环节自动衔接，无需人工参与即可持续运转。
- 自我进化：通过复盘与纠正机制，策略随市场变化持续迭代优化。
- 稳定可靠：运行链路稳定，运行状态、决策依据与交易建议全程可观察、可追溯。

## 主流程

1. **自动规划**：综合市场状况与历史表现，制定阶段性行动计划。
2. **自动生成策略**：依据规划产出可执行的 A 股量化交易策略。
3. **自动回测**：基于历史数据验证策略的有效性与风险水平。
4. **自动运行**：通过验证的策略投入运行，持续产出交易信号与建议，交由人工执行。
5. **自动盯盘**：实时监控市场与持仓，捕捉交易机会与风险。
6. **自动复盘**：定期回顾运行结果，分析得失与问题成因。
7. **自动纠正**：依据复盘结论修正或淘汰策略，并开启下一轮规划，形成持续迭代闭环。

## 数据与信息

- 无初始数据：运行所需数据由 AI 自行获取正规可靠的数据，并存储于 SQLite。
- 信息入口：系统对外获取信息仅通过用户对话，其余内容（策略、分析等）由系统自行生成并存储。

## Agent 架构

参考 [dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype) 的 Agent 架构：

- 采用事件驱动的「触发 → 评估 → 决策 → 工作项 → 执行 → 汇报」闭环。
- 遵循「少占用人的注意力」原则：自主推进工作，仅在需要人决策或产出可用结果时向用户汇报。

## 支撑能力

在 AI 闭环之外，系统还需具备以下平台级能力：

- 多账户：无需登录，支持多账户切换。
- 风险控制：产出的交易建议受风险规则约束，防范极端风险。
- 绩效分析：对策略表现与运行结果进行统计、归因与可视化呈现。
- 策略安全：策略与数据本地存储，防止策略泄露。
