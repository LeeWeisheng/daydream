# 需求描述

## 项目概述

Daydream 是一款面向 A 股市场的 AI 量化决策辅助桌面应用。系统以「自动规划 → 自动生成策略 → 自动回测 → 自动运行 → 自动盯盘 → 自动复盘 → 自动纠正」为主链路，AI 自主完成策略构思、验证、决策与迭代的完整闭环，产出交易建议；交易由人工执行，人工同时负责监督与兜底。

## 行业共识

社区主流量化平台（QMT、PTrade、掘金、聚宽、米筐等）已形成「数据 → 研究 → 回测 → 模拟 → 实盘 → 分析」的一体化能力共识。本项目借鉴其中的数据、研究、回测与分析能力，不涉及模拟盘与实盘交易（交易由人工完成），并以 AI 全自动决策闭环替代人工研究驱动，形成核心差异。

## 核心目标

- 决策闭环自动化：从规划到纠正的决策环节自动衔接，无需人工参与即可持续运转。
- 自我进化：通过复盘与纠正机制，策略随市场变化持续迭代优化。
- 稳定可靠：运行链路稳定，运行状态、决策依据与交易建议全程可观察、可追溯。

## 主流程

1. **自动规划**：综合市场状况与历史表现，制定阶段性行动计划。
2. **自动生成策略**：依据规划产出可执行的 A 股量化交易策略。
3. **自动回测**：基于历史数据验证策略的有效性与风险水平。
4. **自动运行**：通过验证的策略投入运行，持续产出交易信号与建议，交由人工执行。
5. **自动盯盘**：实时监控市场与持仓，捕捉交易机会与风险。
6. **自动复盘**：定期回顾运行结果，分析得失与问题成因。
7. **自动纠正**：依据复盘结论修正或淘汰策略，并开启下一轮规划，形成持续迭代闭环。

## 数据与信息

- 无初始数据：运行所需数据由 AI 自行获取正规可靠的数据，并存储于 SQLite。
- 信息入口：系统对外获取信息仅通过用户对话，其余内容（策略、分析等）由系统自行生成并存储。

## 界面与布局需求

### 总体布局

- 页面整体采用 **header（顶栏）+ sider（侧边导航）+ content（内容区）** 布局。
- **自绘标题栏**：无论 macOS 还是 Windows，窗口控制按钮（macOS 交通灯 / Windows 最小化、最大化、关闭按钮）均位于 header 中，不单独占用一条系统标题栏。
  - macOS：`titleBarStyle: 'hiddenInset'`，交通灯悬浮于 header 左上角，header 左侧内容为其预留空间。
  - Windows：`frame: false`，header 最右侧渲染自定义窗口控制按钮（最小化 / 最大化还原 / 关闭）。
  - header 整体为可拖拽区域（`-webkit-app-region: drag`），交互控件标记 `no-drag`。

### Header 布局

- **左侧**：账户切换（Text Button + Dropdown）；其右侧为「添加账户」图标按钮。
- **右侧**：Agent 启动/停止、运行模式（手动/自动）、主题（亮/暗/系统）三个操作均为**点击按钮直接切换**（tooltip 简化为当前状态名）；Windows 窗口控制按钮随全屏状态带过渡动效隐藏。
- **全屏适配**：全屏时不为交通灯（macOS）或窗口控制按钮（Windows）预留空间，预留空间带过渡动效（250ms，Material standard easing）。
- **运行模式**：
  - **手动模式（默认）**：审批（策略上线/停用/纠正）与信号需人工处理。
  - **自动模式（策略验证用）**：自动处理审批与信号，无需人工干预——Agent 产出的审批类决策自动批准并执行，激活/停用请求直接生效，全程写入对话流留痕；真实交易边界不变（不代执行交易）。

### Sider 导航

- 导航自研实现，**不使用 antd 默认菜单样式**。
- 侧边栏**始终展开**（显示图标 + 导航名称），不提供收起功能。
- 菜单仅包含六个页面：**首页、交易、策略、规划、数据、设置**。
- 与上述六个页面无关的功能一律删除。

### 页面需求

#### 首页

- 内容分为左右两列：
  - **左列**：与 Agent 的对话流（用户消息与 Agent 消息/汇报，可使用 `@ant-design/x` 等开源包实现），支持向 Agent 下达指令与回答问题。
  - **右列**：统计数据与重要内容（Agent 状态、账户概览、最近信号、待决策事项、数据状态等）。**不使用卡片组件**，各区块之间以**虚线**分隔。
  - 左右两列之间以**实线**分隔。

#### 交易

- 常规交易内容：买入股票、卖出股票、持仓管理、仓位管理、资金统计（总资产、可用资金、持仓市值、盈亏）、成交记录、交易建议（Agent 信号）、预警。
- 交易由人工执行：买入 / 卖出在应用内录入，联动更新可用资金与持仓；Agent 仅产出交易建议。

#### 策略

- **每个用户（账户）只能有一个策略**。
- 策略 = 交易策略（选股域、入场/出场条件、组合配置）+ 用户偏好（风险偏好、投资风格、持股周期、仓位限制、自主级别、通知偏好等）。
- 策略必须**可视化**：无论修改还是浏览，均以可视化方式呈现与编辑（表单化 / 结构块编辑，辅以 JSON 高级编辑与版本历史）。

#### 规划

- 展示 Agent loop 的执行规划：将 Agent loop 的**执行时间点**（盘前规划、盘中盯盘、收盘运行决策、盘后数据更新与复盘等节律）与**执行内容**（当前行动计划、工作项队列、最近事件）可视化呈现。

#### 数据

- 包含股票数据（股票列表、日 K 线、指数数据、实时行情、数据状态等），**越全面越好**。
- 支持**一键从公开数据源同步**（全量初始化 + 每日增量更新），进度可见。
- 数据支持增删改查，**Agent 运行时同样可操作**（不因 Agent 运行而锁定）。

#### 设置

- 账户信息：账户名称修改、账户删除。
- 模型信息：模型 **baseURL、模型名、上下文长度、调用频率上限等内置默认预设**（内置多家主流服务商预设，选择预设自动填充 baseURL / 模型名，用户仅需填写 API Key / Token）。
- 主题、数据源偏好、通知偏好、日志导出等。

## Agent 运行规则

- **常驻运行**：Agent 一旦启动（用户点击运行按钮），只要用户不点击停止就一直运行；**切换用户不影响 Agent 运行**（Agent 资金视角跟随活跃账户）。
- **关闭软件时停止运行**：应用退出时优雅停止 Agent 执行（进程退出，不产生后台残留）；运行开关状态持久化，重启后恢复上次状态。
- Agent 停止运行后：交易节律事件（规划/盯盘/运行决策/复盘）不再触发，自动工作项不再调度；用户对话仍可用；数据增量更新照常（数据是全局基础设施）。

## Agent 架构

参考 [dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype) 的 Agent 架构：

- 采用事件驱动的「触发 → 评估 → 决策 → 工作项 → 执行 → 汇报」闭环。
- 遵循「少占用人的注意力」原则：自主推进工作，仅在需要人决策或产出可用结果时向用户汇报。

## 支撑能力

在 AI 闭环之外，系统还需具备以下平台级能力：

- 多账户：无需登录，支持多账户切换；每个账户唯一一份策略。
- 风险控制：产出的交易建议受风险规则约束，防范极端风险。
- 绩效分析：对策略表现与运行结果进行统计、归因与可视化呈现。
- 策略安全：策略与数据本地存储，防止策略泄露。
